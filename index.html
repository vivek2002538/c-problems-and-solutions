INTRO

What is jQuery?

jQuery is a lightweight JavaScript library that makes it much easier to select elements, change them, react to user actions, and animate things — with far less code than plain JavaScript needs. This page is a quick, self-contained intro: a short explanation followed by demos you can actually click on.

Why people still use it

  • Short syntax — $("#box").hide() instead of several lines of document.querySelector + style changes.
  • Cross-browser consistency — jQuery smooths over differences between browsers so you write one line of code instead of branching logic.
  • Chaining — most methods return the same object, so you can stack actions: $("#box").addClass("on").fadeIn().
  • Built-in effects & AJAX helpers — fading, sliding, and simple network requests come out of the box.

Loading it

One script tag, usually right before </body>:

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<script>
  $(function () {
    // Your code runs here once the page has loaded
  });
</script>
